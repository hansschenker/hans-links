# Hans Links

A local web app that finds exported Chrome history files, lets you edit or remove links, and saves the remaining list to [`hansschenker/hans-links`](https://github.com/hansschenker/hans-links).

## Run

Requirements: Node.js 20 or newer and an authenticated GitHub CLI (`gh auth status`).

```powershell
cd C:\Users\hanss\hans-links
npm start
```

Open <http://127.0.0.1:4173>.

The app scans its own folder for either filename style:

- `history-YYYY-MM-DD.html`
- `history_YYYY-MM-DD.html`

It reads the encoded JSON generated by the Better History Chrome extension. Previously saved URLs and files recorded in `imported-history.json` are skipped. Pressing **Save to GitHub** updates `hans-links.md` and `imported-history.json` in the GitHub repository, then mirrors both files locally. Links are saved in the standard Markdown format `[text](URL)`. When no title is available, the URL is used as the text.
